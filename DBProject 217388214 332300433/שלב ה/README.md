# דוח פרויקט - שלב ה' (ממשק גרפי למערכת רחפנים)

בשלב זה פיתחנו ממשק גרפי (GUI) המאפשר למשתמש קצה לגשת, לנהל ולהפעיל את בסיס הנתונים שלנו בקלות, מבלי לכתוב קוד SQL.

## הוראות הפעלה וכניסה למערכת
כדי להפעיל את המערכת, יש לוודא שמותקנות ספריות הפייתון הנדרשות:
```bash
pip install customtkinter psycopg2
```
1. פתח את הקובץ `database.py` וודא שפרטי ההתחברות (user, password, host, port) מעודכנים לשרת שלך.
2. הרץ את הקובץ הראשי מהטרמינל (בתוך תיקיית `שלב ה`):
```bash
python main.py
```
3. חלון האפליקציה ייפתח. תוכל לנווט באמצעות התפריט השמאלי בין המסכים השונים.

## הכלים ששימשו לפיתוח ודרך העבודה
את המערכת בחרנו לפתח בשפת **Python**. שפה זו נבחרה בזכות קריאות הקוד שלה, הפשטות, והתמיכה המצוינת בספריות חיצוניות.

*   **GUI (ממשק משתמש):** השתמשנו בספריית `customtkinter`. זוהי מעטפת מודרנית לספריית ה-Tkinter המסורתית. היא מאפשרת עיצוב נקי ויפהפה, תמיכה במצב לילה/יום (Dark/Light mode), רדיוסים עגולים לכפתורים, וקומפוננטות שנראות כמו אפליקציה עדכנית לכל דבר.
*   **Database (מסד נתונים):** השתמשנו בספריית `psycopg2` כדי לנהל את הגישה ל-PostgreSQL. בנינו מחלקת `Database` מרכזית שעוטפת את כל השאילתות, מטפלת בשגיאות, ודואגת להתחברות ולניתוק מסודרים.
*   **ארכיטקטורה:** כדי לשמור על קוד נקי ותחזוקתי, המערכת חולקה למספר קבצים:
    *   `main.py`: המסגרת החיצונית ותפריט הניווט.
    *   `database.py`: חיבור ללוגיקת הנתונים.
    *   `gui_drones.py` & `gui_missions.py`: מחלקות המטפלות במסכי ה-CRUD, עם שילוב של `JOIN` כדי להציג שמות במקום מזהים.
    *   `gui_advanced.py`: מסך המרכז הרצת שאילתות משלב ב' (מוזרקות אוטומטית לטבלה דינמית) והפעלת פרוצדורות משלב ד'.

## צילומי מסך והסבר על השימוש במערכת

### מסך ראשי (Dashboard)
זהו מסך הפתיחה של המערכת. הוא מברך את המשתמש ומאפשר לו לנווט בין המסכים השונים דרך תפריט הצד (Sidebar).
![Dashboard](./screenshots/dashboard.png)

### ניהול רחפנים (CRUD)
במסך זה ניתן לראות את כל הרחפנים בצי בתוך טבלה (Treeview). המערכת מבצעת שאילתת `JOIN` מאחורי הקלעים ומציגה את **שם המודל** במקום מזהה המודל.
- **הוספה (Add New Drone):** הזן מזהה רחפן, מספר סידורי, מזהה מודל, תאריך רכישה וסטטוס ולחץ על הלחצן. (שים לב: הזנת תאריך עתידי תיחסם על ידי טריגר משלב ד' ותקפיץ הודעת שגיאה על המסך).
- **עדכון חכם (Fetch Data):** הזן את מזהה הרחפן (Drone ID) ולחץ על כפתור `Fetch Data`. המערכת תשלוף אוטומטית את שאר הנתונים לשדות. לאחר מכן תוכל לשנות אותם וללחוץ `Update Drone`.
- **מחיקה (Delete Drone):** הזן מזהה רחפן ולחץ `Delete`. במידה ולרחפן יש משימות היסטוריות או היסטוריית טיפולים, המחיקה תיחסם כדי לשמור על שלמות הנתונים (Foreign Key Constraint) ותוצג שגיאת מסד נתונים.
![Drones CRUD](./screenshots/drones.png)

### ניהול משימות (CRUD)
מסך הפועל באופן זהה למסך הרחפנים, אך עבור טבלת המשימות.
גם כאן מבוצע שילוב נתונים (JOIN) המאפשר לראות בטבלה את **שם הלקוח** עבורו מתבצעת המשימה במקום את מזהה הלקוח. המסך תומך בהוספה, מחיקה ועדכון חכם על פי מזהה המשימה. עמודת ה-Field_ID (שנוספה בשלב ד') מוצגת ונערכת גם היא.
![Missions CRUD](./screenshots/missions.png)

### מסך פעולות מתקדמות (שאילתות ופרוצדורות)
זהו המסך המשלב את הקוד שנכתב בשלבים ב' ו-ד' אל תוך הממשק הגרפי. המסך מחולק לשני אזורים:

**א. הפעלת פרוצדורות (משלב ד'):**
1. כפתור **Auto-Assign Urgent Missions**: לחיצה עליו מריצה את הפרוצדורה `auto_assign_urgent_missions(4)`. הפרוצדורה סורקת את הטבלה המרוחקת `pest_reports` כדיווחים עם חומרה מ-4 ומעלה, מאתרת עבורם רחפן מתאים ופנוי, משבצת אותו למשימה ומשנה את הסטטוס שלו ל-'In Mission'. בסיום הפעולה קופצת הודעת הצלחה ואפשר לראות את השינוי במסכי ה-CRUD.
2. כפתור **Flag Old Drones for Maintenance**: ליד הכפתור יש שדה הזנת תאריך (Cutoff Date). לחיצה על הכפתור מריצה את הפרוצדורה `flag_drones_for_maintenance` עם התאריך שהזנת כפרמטר. הפרוצדורה מאתרת רחפנים שנרכשו לפני תאריך זה ומעבירה אותם לסטטוס 'Maintenance'.

**ב. הרצת שאילתות מורכבות (משלב ב'):**
1. כפתור **Run Query 5: Expiring Certifications**: כפתור זה עוזר למנהל הצי לדעת למי צריך לחדש רישיון. הרצת השאילתה שולפת את כל מפעילי הרחפנים (Operators) שהרישיון שלהם פג תוקף ב-60 הימים הקרובים, כולל רשימת המודלים שאליהם הרישיון תקף. התוצאה מוזרקת מיד לטבלה הדינמית בתחתית המסך.
2. כפתור **Run Query 8: Flight Alerts by Hour**: לחיצה על הכפתור מריצה שאילתה מתקדמת המנתחת את התראות הטיסה בטבלת `flight_alerts`, מקבצת אותן לפי שעות ביום (בעזרת `EXTRACT HOUR`), ומציגה את מספר ההתראות המצטבר בכל שעה ואת ממוצע רמת החומרה. התוצאות מוצגות בצורה מסודרת בטבלה.
